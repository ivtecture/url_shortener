# Сокращатель ссылок с защитой паролем

Сервис превращает длинный URL в короткий (`https://example.com/very/long/path` → `http://localhost:3000/aB3xK9`). Если при создании задан пароль, переход по короткой ссылке сначала показывает страницу ввода пароля, и только после правильного пароля происходит редирект.

## Запуск

```bash
npm install
npm start        # или npm run dev (автоперезапуск при изменении кода)
```

Сервис доступен на http://localhost:3000 (порт можно переопределить через `PORT`).

## Как пользоваться

1. Откройте главную страницу, вставьте длинный URL. Пароль и свой короткий код — опционально.
2. Полученную короткую ссылку можно распространять.
3. По ссылке без пароля — мгновенный редирект. По ссылке с паролем — страница ввода пароля, затем редирект.

## Структура

- `server.js` — приложение Express и маршруты
- `src/db.js` — SQLite (встроенный `node:sqlite`, файл БД — `.data/links.db`)
- `src/crypto.js` — хэширование паролей scrypt (никаких паролей в открытом виде)
- `src/urlcode.js` — генерация и валидация коротких кодов
- `views/` — EJS-шаблоны (форма создания и страница пароля)

## Примечания

- Пароль хранится как `scrypt$salt$hash` (соль на каждый пароль).
- Свой код: 3–32 символа — латиница, цифры, `_`, `-`.
- Коды `favicon.ico`, `robots.txt`, `health` зарезервированы.
- Поддерживаются только `http://` и `https://` ссылки.
